# 🚀 TheAdBook - Digital Out-of-Home (DOOH) Advertising CMS

TheAdBook is a comprehensive, full-stack Content Management System (CMS) designed specifically for managing and scheduling digital out-of-home advertising campaigns, media assets, playlists, and connected display devices in real-time.

---

## 🌐 Live Application Links
* **Live Frontend App:** [https://theadbook.vercel.app](https://theadbook.vercel.app)
* **Live Backend API Core:** [https://theadbook-backend.vercel.app](https://theadbook-backend.vercel.app)

---

## 🛠️ Tech Stack & Libraries

### **Frontend**
* **React.js / Vite** - Fast and modern user interface
* **Tailwind CSS** - Utility-first styling for responsive design
* **Axios** - Secure HTTP client for API communications
* **Zustand** - Lightweight state management
* **Recharts** - Interactive data visualization and analytics graphs
* **jsPDF & html2canvas** - Client-side report and invoice PDF generation/export

### **Backend**
* **Node.js & Express.js** - Robust RESTful API architecture
* **MongoDB & Mongoose** - Scalable NoSQL database & ODM
* **JWT (JSON Web Tokens)** - Secure session & role-based authentication
* **Helmet & Morgan** - Security headers and HTTP request logging

---

## ✨ Key Features

* **🔐 Secure Authentication:** Role-based access control with JWT encryption.
* **📺 Device & Screen Management:** Monitor live DOOH screen statuses, health logs, and location mappings.
* **📁 Media & Playlist Engine:** Upload heavy assets (up to 50MB) and build dynamic playback playlists.
* **📅 Smart Scheduling:** Automate campaign scheduling and display rotations seamlessly.
* **📊 Analytics & Reports:** Real-time dashboard insights with dynamic graphs, billing, and PDF report downloads.
* **⚡ Serverless Deployment:** Optimized for high availability via Vercel cloud deployment.
